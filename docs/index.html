    API documentation

    ModuleDescription
    djson.binding Binding system for djson. Provides UDAs and methods to convert between D types and JValue.
    djson.builder Helper functions for building JSON objects and arrays fluently.
    djson.jsonpath JSONPath (RFC 9535) support: expression compiler and queries over a JValue tree.
    djson.parser Internal and public parsing logic for djson. This module implements lazy parsing, skipping, and full eager parsing.
    djson.value Core data structures and API for djson. This module defines JValue, JObject, and JArray types.
    djson.walk Single-pass, callback-based traversal of a JSON document.
    djson High-performance, lazy JSON library for D.
