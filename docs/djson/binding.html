    Module djson.binding

    Binding system for djson. Provides UDAs and methods to convert between D types and JValue.

    Functions

    NameDescription
    fromJSON(v) Convert a JValue to a D type T. Throws JSONException if a required field is missing or types mismatch.
    toJSON(value) Convert a D type T to a JValue.

    Structs

    NameDescription
    JSONPostProcess UDA to apply a postprocessing function during toJSON. The function signature must be JValue func(FieldType v).
    JSONPreProcess UDA to apply a preprocessing function during fromJSON. The function signature must be FieldType func(JValue v).

    Enums

    NameDescription
    JSONIgnore UDA to explicitly ignore a field from JSON binding. Useful when the parent struct is marked with @JSON.

    Aliases

    NameTypeDescription
    JSON djson.binding.JSONImpl!(false) UDA to mark a field for JSON binding and/or specify a custom path. Can be applied to: - A struct/class: all public fields are included. - A field: that field is included. - A field with path: @JSON("flat_key"), @JSON("/ptr/path"), or @JSON("variadic", 1, "key").
    JSONOptional djson.binding.JSONImpl!(true) UDA to mark a field as optional. If missing in JSON, the field will retain its init value. Supports the same path mapping as @JSON.
